# 模型修复

## 先区分问题出在哪里

- 直接解析或渲染 GLB 时应用节点的变换。文件空间、物体局部空间和朝向相差一个轴时，容易误判哪一侧有问题。定位网格问题时保留一张带坐标轴的多角度预览。
- 已合并在一个物体里的网格可能有很多连通分量。统计前按位置识别 UV 缝的重合顶点。决定删几何前查看连通性和截面，判断它是独立碎片、仍连在主体上的伪造结构，还是源图中真实的薄片。
- 对腰口、袖口、肩带、口腔等部位做近看和截面检查。贴图里的暗部会伪装成开口。射线或检查边界环能帮助判断封面、厚度或缝隙究竟在哪里。

## 修形和减面

- 先留住外形和需要分开的结构，再处理口袋、缝线、毛发和鳞片等细节。包带可以用形态键带动连续网格的接缝，也可以按后续编辑方式独立拆件。帽子可在清理重复帽檐后补回侧面，再检查原正面帽檐和原图标记。
- 衣物贴体主要取决于角色体型和动作。腰口和裤脚只移除生成的封面，保留口沿和外边缝。薄夹克可能有内外两层，激进减面或按最近面投射法线会在帽兜、袖口和拉链附近产生大片折面。以渲染验证选择减面程度，必要时保留较高面数供贴体和蒙皮。
- 扭斜或多生结构的动物先修休止姿态。重复尾巴可切除后按主身体曲率补面并匹配邻近贴图。弯曲的尾可以按曲线弧长重新排布横截面，分配权重后验证摆动和着地。闭合嘴部需要大幅张口时，先检查上下颌是否连在一起，按需要拆出口腔、下颌、牙齿和舌。鸟的长飞羽与趾爪要检查剪影和接触，折翼可以用形态键补足大幅关节转动时的体积损失。
- 当减面或布尔产生的新面跨过旧 UV 岛时，局部设 UV 或重烘贴图。对补面边缘检查光照、贴图和几何的接续。颜色贴图按 sRGB 导入，法线和金属度/粗糙度按 Non-Color 导入。单套图集可减少独立材质面。使用填充边缘的图集时，在最终输出分辨率检查远景采样是否产生接缝。
- 生成的 GLB 有时把主体颜色放在自发光通道。验明原贴图和用途后，让普通布料、皮革和金属的底色受游戏光照影响，并对照日夜表现以及独立物品预览的颜色。
- 验收保留特征和薄片，查看同角度原版/候选对比。可同时量面数、边界环、目标体积和轮廓重合度。轮廓相似的两个版本仍可能在近看时出现法线错误或关节穿插。

## 源件到游戏的对照验收

1. 用相同取景范围、光照和取样角度查看原始 GLB 和重新打开的导出 GLB。服装重点看正侧背面的轮廓、衣口、褶皱、拉链、袋口和缝线。再到游戏检查实际穿戴效果、道具落地效果和常用动作，按使用入口取样。物品图与人物穿戴状态要对得上，鞋、帽等配件旋转到侧面时也能确认实际挂载了对应网格。
2. 导出 GLB 已出现大块尖折面、破洞或贴图拉伸时，逐步对照焊接、减面、贴体和贴图缩放前后的结果。薄布、内外层和 UV 岛不能因距离近就合并。先试在未贴体变形的源网格上减面，保留 UV 与平滑法线，再验证贴体结果。根据可见细节调整局部拓扑、面数或贴图档位，并以对照渲染决定取舍。
3. 导出 GLB 在 Blender 中正常时，逐段核对引擎导入后的材质、法线、纹理压缩、LOD、蒙皮和挂载。材质或光照难以判断时，补查基础色与 PBR 预览。角色画板单独减面或烘焙时，对它也做近景对照，避免好看的游戏网格在画板上变粗糙。

雨线营地夹克的原始 GLB 有清楚的前拉链和胸袋。旧运行模型在贴体及减面后的对照中已经丢失这些细节。相同视角下能看到拉链、胸袋和布褶，转身能看清袖口及衣摆，是这件夹克重新导出的验收依据。


## 植被的近远景与接地

整树同时包含厚实树干和大量薄叶。整体减面后，按材质查看各级网格的三角数和垂直覆盖范围。出现远处只剩枝叶时，可给树干、枝条和叶片分别分配预算。扫描岩体的纹理接缝若在减面时裂开，可先焊接重合坐标，保留面角 UV。

将模型的落点对齐低处顶点形成的实际根颈或岩脚。在游戏里沿坡面走过远近切换距离，检查树冠轮廓、根脚和下坡侧的悬空。大片花草可从原模型烘焙多视角簇，近路保留带茎叶的立体植株，侧看和俯看时都能读出层次。
