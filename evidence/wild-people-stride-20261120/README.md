# 野人步态与转身

四套普通和高级野人在 Blender MCP 中从玩家的 `Walk` 和 `Run` 取样，使用相同的 23 个身体与四肢骨名映射姿态，再按各模型的腿长、赤脚或靴底校准落脚。左右握点仍跟随原手骨。跛行缩短受伤侧的负重时间和抬脚高度。新加的 `TurnLeft`、`TurnRight` 用两脚轮流支撑大角度转向。[模型与导出验证](asset-checks.json) · [步态烘焙入口](../../scripts/bake-wild-people-locomotion.py)

联机房间依据碰撞后的实际行程推进步态相位，客户端按画面中的位置插值采样。大角度转向依实际转角采样。旧客户端每帧暂停动画混合，以下从站姿切入的样本显示双脚随身体平移。新版按帧推进混合。[步态同机位对照](stride-comparison.jpg) · [转身同机位对照](turn-comparison.jpg)

Godot 4.7.2 Compatibility 在 Apple M1 上用相同机位、采样间隔及碰撞网格对照普通男性和高级女性。表格范围为两名角色各自左右支撑脚的平均横移。支撑脚取距人物脚下高度 18 mm 内的实际蒙皮鞋底或脚底，测量连续样本的接触点。新版四套模型的全部测试通过。[原版数据](baseline.json) · [新版数据](stride-checks.json)

四套 GLB 的模型网格、骨架权重、材质、贴图和原有八段非移动动画逐项与原版一致。新版每套 14 段，通过实机骨骼与姿态复验。原运行入口通过 60 项生命周期、6 条真实林地寻路及四套模型的面板和装备回归。[原生姿态检查](engine-poses.json) · [游戏回归](regressions.json)

同一隔离房间的两个 WebSocket 客户端从不含步态相位的旧存档开始，收到同一房间时钟下的 53 组一致快照。3 名 NPC 真正走路、追逐、跛行和转身。步态相位换算的行程与位置变动最大差 2.9 mm，大角度转身保持原地。[双客户端记录](loopback.json)

复拍时将 [脚底测量脚本](../../scripts/test-coop-wild-people-stride.gd) 放进对应版本的隔离 `coop` 工程，创建 `frames/`，启动原生 Godot 并传入 `-- --capture`。原版额外传入 `--baseline`。动作候选与原件备份留于本机 `dist/asset-work/wild-stride/`。本轮对照使用原生客户端和隔离联机房间。
