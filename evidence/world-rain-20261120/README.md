# 雨丝位置与遮挡复验

雨丝位置使用世界坐标和房间时钟。近镜头的雨丝逐渐变淡，条形边缘和末端带透明过渡。每滴在所在位置采样与草木共用的阵风，雨量变化时逐渐增加或减少可见滴数。屋顶和矿洞石壁按同一条倾斜的雨滴轨迹做遮挡。

Godot 4.7.2 在 Apple M1 的 Compatibility 渲染器上以 1280 × 720 拍摄。前后版都锁定房间时间为 94.5 秒，关闭雨丝的参考帧保留相同的灯光、湿地和几何。林地画面中，雨丝造成通道变化超过 64 级的像素由 1,811 降到 286。镜头与房间时间锁定，将雨区原点移动约 0.66 米，可辨的 767 个雨丝像素中有 764 个留在原位置。房间时间向前一帧后有 1,775 个像素变化超过 8 级。 [雨丝前后](rain-before-after.jpg) · [测量](measurement.json)

原木屋、修好的营地和两座矿洞都能挡雨。斜放屋顶使用放置后的角度挡雨。搬走屋顶的原位置和矿洞外露天坡道，两组在开启遮挡前后没有超过 8 级的像素差。跳过镜头后方雨丝的遮挡运算后，以上遮挡对照的截图逐像素一致。 [煤矿入口对照](mine-cover.jpg)

复拍使用 [原生机位脚本](../rain-shelter-20261120/capture.gd)，参数为输出目录和 `dist/coop-atlas/zones` 的绝对路径。比较工具接收修前截图目录、修后截图目录和证据输出目录。 [截图比较工具](compare.py)
