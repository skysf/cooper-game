# 高级同伴的裤腿与靴子

普通男女的裸腿、束带和凉鞋属于原本的服装。两套高级 Blender 源也保留了这些几何，并在外面叠裤腿和靴。现行近景里，高级款的靴尖可看见皮肤，女款另外露出旧凉鞋的边。新方案把两套高级款的下腿各做成一件布裤和保留实体鞋底的靴。男款采用一道棕色绑带，女款采用两道灰绿绑带和稍收的裤腿。两款都在原高级参考图的深色布面上采样，沿用打包图集和上身造型。

## 对照

在 Godot 4.7.2 中用实际 `WildPeopleScene` 抽取两套高级款各 13 个时刻的房间动作，包括站姿、三段步行、左右跛行、持物、下跪、休息、倒地和取水。使用相同骨姿，在 Blender Cycles CPU 中并排渲染；两侧 CPU 投影以 3 mm 的采样间隔检查脚部窗口。表内为各机位合计可见的裸脚、旧绑带及凉鞋的样点数。

| 动作 | 男款旧 → 候选 | 女款旧 → 候选 |
| --- | ---: | ---: |
| 站立 | 124 → 0 | 309 → 0 |
| 行走 | 126 → 0 | 292 → 0 |
| 持物 | 62 → 0 | 202 → 0 |
| 坐姿休息 | 135 → 0 | 301 → 0 |
| 跪姿 | 1,509 → 0 | 1,663 → 0 |
| 倒地 | 99 → 0 | 194 → 0 |

两款全身投影轮廓与各自原件的交并比为 98.50%–100%。抽样中左右下腿的外壳均无三角交叉。两款实体靴底各 120 个位置、鞋底落点和整模最低点逐值一致，25 骨与逆绑定逐项相同。每款的 16 段动画共 1,200 条通道逐值一致，Godot 中的持物挂点偏差均为 0。两款为 13,016 个三角面，原男款 15,084、原女款 15,300。运行表面男款 10、女款 8，贴图以原 JPEG 字节导出。

## 现有步态量测

原步态的支撑重心由全部低处脚顶点计算，高级款旧档中同时包含实际靴底、穿在里面的裸脚与凉鞋。早期动作也用同一套混合顶点求支撑中心。移除里面的旧几何后，原步态检查在 9 个步行、跑步或跛行条件超出脚滑门槛。将新旧两版都改用真实外靴采样，得到相同的 9 个超限条件和相同的结果。步行双脚平均滑移，男款两侧约 0.155–0.179 m/s，女款约 0.113–0.129 m/s。角色场景四款各 16 段动作以及取水、采果回归通过。隔离候选保留历史动作，正式导出仍以原文件为准。

## 四款的落脚复测

四套角色共用 [步态烘焙入口](../../scripts/bake-wild-people-locomotion.py)，取玩家站、走、跑三个动作，走、跑、双侧跛行分别复用 1.38、1.92 和 1.04 m 的周期位移，左右转向各以 90° 为一个周期。按 48 FPS 烘焙时，走、跑、跛行和转向分别写入 48、36、54 和 30 个时间段。实机以实际位移或转角驱动快照相位，客户端用可见根节点与权威位置的差修正显示相位。两条工作动作只共用肢体解算函数。 [四款源生成](../../scripts/build-wild-people.py) · [权威移步](../../coop/wild_people.gd) · [显示相位](../../coop/wild_people_scene.gd) · [工作姿态](../../scripts/bake-wild-people-work.py)

Blender MCP 在内存中逐款评估了六段动作，每段均匀取 240 个时间段。裸脚用可见皮肤，凉鞋用外底，两套高级款各用实体靴底。普通男款每只脚仍采同样的 263 个点，凉鞋由 383 点中选取 72 个外底点，高级男、女各由 323 和 443 点选取 60 个外底点。外底取样将两套高级款站撑时的支撑重心平均滑速从步行 0.141–0.188 m/s、跑步 0.283–0.379 m/s 降至约 0.002 m/s。按标称跑步周期单独跟踪相邻时刻均位于地面上方 5 mm 内的同一批材料点，两款的瞬时滑速 P95 从 1.94–2.05 m/s 升到 2.54 m/s。两种算法都把最低点控制在约 4 mm。近似不动的重心会掩盖鞋底打滑。 [独立探针](probe-gait-contact.py) · [逐款逐段数据](gait-proof.json)

下一份候选可用各款的实体外底建立支撑点，按实际足部旋转和接触位置调整踝点。先测主体支撑相里的落脚稳定性，再用鞋跟落地、脚掌承重、脚尖离地检查换相。跛行分别保留两侧的支撑时长和抬脚幅度。若采用滚动支点，接触点应随鞋底姿态从后向前移动，稳定支撑段内的同一材料点应贴地且少滑。离地到摆腿之间检查位移和速度是否连续。

用同一条 Godot 平地路线在四套模型上实测巡逻、步行、跑动、双侧跛行和双向转身。每段同时记录脚底标记速度、支撑重心漂移、最低点、两脚高差和状态切换时的相位。用真实门框、斜板、地板和自由同伴路线补查贴地，确认权威走速、路径、双手握点及其余十段动画的回归。隔离候选先做这些 CPU 检查，再用同机位的连续帧检查脚跟与脚尖。 [现有 Godot 路线脚本](../../scripts/test-coop-wild-people-stride.gd)

```sh
gait_report=$(mktemp)
./scripts/start-blender.sh --background --python-exit-code 1 \
  --python evidence/wild-people-elite-fit-20261120/probe-gait-contact.py -- "$gait_report"
```

## 重建隔离件

Blender MCP 在独立后台打开 [高级男款源](../../art/wild_man/male_elite.blend) 与 [高级女款源](../../art/wild_man/female_elite.blend) 的副本，保留网格、绑定和原动作轨。脚侧都有可编辑的 `.blend` 与游戏用 GLB。重新生成的 GLB 哈希与采样件一致，复开检查能读到完整蒙皮与动作。可从当前源重建到一个临时目录。

```sh
elite_review=$(mktemp -d)
./scripts/start-blender.sh --background --python-exit-code 1 \
  --python evidence/wild-people-elite-fit-20261120/build-candidate.py -- "$elite_review"
```
