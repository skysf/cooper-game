# 静态寻路的冷启动

同一 Godot 服务进程共享静态地形。旧版在同伴第一次去溪边时扫描 `175,421` 个格点，再增加 NPC 的 14 cm 路线净空。藏獒在跟随主人走远时独立扫描同一地形。旧版回环采样中，NPC 的基础图与净空耗时分别为 `405.781` 与 `27.659 ms`，狗的扫描为 `435.274 ms`。两个时段都发生在玩家已入房后的模拟中。

工作区在服务监听前准备这两张格图。水域、岸线和基础障碍扫描一次，NPC 在该结果上计算自己的净空。地形格图服务进程内复用，室内建造物和角色路线依然各归房间。把两张图都提前建好的一次独立测量由 `886.337` 降到 `459.090 ms`。新旧格图的半米间距、坐标范围、对角模式、所有格点的可通行性完全一致。狗图阻挡 `107,947` 格，NPC 图阻挡 `109,091` 格。两张图的已有容量从服务启动时开始占用。

## 真实双客户端

同一台机器使用相同版本的 Godot 客户端，在独立、空的临时存档中通过回环 WebSocket 加入两个房间。房间 A 从旧档恢复一只等待中的藏獒和需要去溪边取水的自由同伴。客户端给狗下跟随指令，走出 `4.74 m`，狗移动 `4.77 m` 并追到主人 `1.84 m` 内。房间 B 先独立活动，再换入 A，确认同伴与狗的状态同步。所有连接和玩法消息经游戏服务器与客户端网络脚本。

| 指标（毫秒） | 旧版 | 监听前预热 |
| --- | ---: | ---: |
| 进程启动至 `ROOM_SERVER_READY` | 570.154 | 810.307 |
| Godot 服务端初始化工作 | 5.704 | 462.271 |
| READY 至两端收到首个房间快照 | 507.323 | 477.972 |
| READY 至首个跟随回执 | 941.819 | 512.209 |
| 玩家在线的第一个服务端模拟步 | 447.900 | 16.079 |
| 藏獒第一次跟远并使用静态路径的模拟步 | 436.923 | 3.151 |
| 玩家在线时模拟步 P95／最大 | 4.360／447.900 | 4.659／16.079 |
| 狗和 NPC 均做过首次寻路后 P95／最大 | 4.263／6.109 | 4.663／7.323 |
| 两端快照间隔最大 | 553.878 | 135.721 |

这组样本的服务器 READY 推迟 `240 ms`，Godot 初始化多 `457 ms`。另一组同尺寸 A/B 的进程启动至 READY 为 `392 → 825 ms`，READY 至跟随回执为 `918 → 509 ms`。进程启动开销有波动。完整工作区另测的首个模拟步为 `12.659 ms`，狗首次寻路所在步为 `14.422 ms`，在线 P95 为 `4.444 ms`，最大步 `48.043 ms`。三组中，优化版进入房间后均未再次扫描静态格图。这里的计时范围覆盖服务模拟、网络收发和客户端输入回执；帧时为服务端 CPU 耗时。

每条 `server.framesUs` 记录距 READY 的时间、该步工作时长、传给服务端的模拟步长和活跃房间数。前三项用微秒。客户端 `snapshotTimesUs` 保留两个客户端收到快照的时间。

## 碰撞与存档回归

使用上轮两房间构件夹具，预热前后的两房路径点、碰撞和落脚高度逐值相同。实墙与门框阶段的最慢模拟步从 `430.424 ms` 降到 `14.916 ms`。五阶段最高 P95 从 `2.621` 降到 `2.401 ms`。该夹具在拾起和另放的路径阶段仍有约 `25 ms` 的最慢模拟步。

工作区通过 34 项构件与视图检查、6 条 NPC 原有路线、68 项 NPC 生命周期及生存和存档回归。门洞、实墙、木桌、真实倾斜板、叠放地板、狗跟随、原地等待和旧狗档继续通过。两套角色视图在地板上高 `0.18 m`，移走后的首个快照中回到 `0 m`。本地测试使用临时存档和回环端口。

## 复跑

在工作区的两个终端运行。第二条在第一条显示 `ROOM_SERVER_READY` 后执行，输出各自的微秒样本。两房构件回归可单独运行第三条。

```sh
Godot --headless --path coop --script ../scripts/test-coop-navigation-cold.gd -- --port=61481 --save="$(mktemp -d)"
Godot --headless --path coop --script ../scripts/test-coop-navigation-cold.gd -- --clients=61481
Godot --headless --path coop --script ../scripts/test-coop-room-navigation-fit.gd -- --visual
```
