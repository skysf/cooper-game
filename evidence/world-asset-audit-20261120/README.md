# 雨线营地 · 第一轮模型盘点

2026-11-20，以当前工作区运行资源及 4984 发行目录的林地分块为基线。局部截图来自 Apple M1 上的 Godot 4.7.2 Compatibility。复用项目导入设置，包含 GLB 内嵌和外置贴图。盘点、临时导入和渲染均只读使用实际游戏资产。

## 清单

[运行资产清单](inventory.json)列出 67 个包内 GLB 和 7 个林地分块 GLB。九个动态生长模型由 `world.json` 的树种、`grove.gd` 的阶段组合。串流分块来自 `world.json`，七个文件的实测字节与配置一致。包内模型均找到引用，未发现缺失的模型引用或 GLB 外置贴图。10 个 GLB 带蒙皮。

共找到 71 个代码、材质或配方直接或动态加载的图像路径。包内 GLB 另外声明 106 份内嵌图和 49 条外置纹理引用，其中存在共用路径。完整清单记录纹理尺寸和通道用途、材质及面数、LOD 节点、导入设置、骨骼名、动作及本机可用源件。脚本读取和统计资源文件，实际每帧提交量随实例数、可见性和 LOD 变化。

```sh
python3 scripts/audit-coop-3d-assets.py --zones dist/coop-wearables-preview/zones > /tmp/coop-assets.json
```

岩岸、林地、远景树、草和湖岸还有运行时生成或替换的网格与材质，入口记在清单的 `runtime_overrides`。15 个在用模型的可编辑文件目前只在本机的 `dist/ui-mockup/3d/`，下一次变更这些模型时宜把可编辑源件纳入持久位置。矿洞等待后续建造，本轮清单中没有矿洞模型。

## 局部核验

| 对象 | 结果与下一轮重点 |
| --- | --- |
| 玩家、装备与飞船 | 使用已验收的[穿戴同机位对照](../camp-ui/wearables-detail.jpg)和[飞船同机位对照](../airship-hull-detail.jpg)。当前夹克为 37,945 三角面，颜色 1K。飞船为 89,988 三角面，颜色、法线 2K。本轮保持这些已交付资产。 |
| 四套野人 | 各 25 根骨骼及 12 段动画。复跑例行三视图、面部、握点与 12 段逐帧采样，错误为零。走路阶段最低顶点距地约 2.0–8.1 毫米，倒地采样为 −1.2 至 12.4 毫米。相同骨名有 23 个，涵盖玩家走跑的躯干和四肢，NPC 独有左右握点。玩家动作库另包含 30 个手指骨轨道，仍需映射静止方向、保住握点并试跑。NPC 无独立转身或工作动作，客户端按固定片段时间播放，服务端移动还会随目标和伤腿改变速度。下一轮用实际移动量验证支撑脚是否滑动，再验证转弯、蹲工作业和工作交互。 |
| 藏獒 | 原始参考的前后肢之间有更清楚的胸腹段，游戏模型的鬃毛、腰和后躯在侧面聚得更紧。以 Blender 静止绑定中 `Fore.Upper.L` 到 `Hind.Upper.L` 的骨头原点沿前向 Y 投影，右侧重复，均为 0.395 米。Godot 对应纵轴 −Z。Blender 源与重新导入的运行档都是 18,274 三角面，双向顶点误差不超过 0.34 微米，骨骼原点误差不超过 0.20 微米，九段动作名和时长一致。两个 GLB 存档散列相同。优先在源件局部增加胸腹长度，同时回归站、走、跑、跛、趴、起身和联机收养。 |
| 鳄鱼与老鹰 | 鳄鱼的待机、咬击和游姿能显示上下颌分离、尾部和四足。老鹰的栖停和滑翔动作都可播放。当前 `camp_storage_scene.gd` 尸体分支查找 `Perch`，实际 GLB 动作是 `PerchIdle` 等，当前分支跳过姿势采样后只转动模型。优先补老鹰从坠落到着地的翼、躯干和腿的姿势，尸体保留实际贴地帧，然后在联机实际地表复验。 |
| 营地近景 | 木桌、水壶、油灯、编织篮、两种木箱、两种桶、营火和路牌均实际导入渲染。地面道具的模型底缘都位于 Y=0，灯的原点是挂点，底缘距挂点 0.582 米。模型侧可看到桌板纹理、箱锁和桶箍，后续实际地图检查门廊遮阴下材质和放置接触。 |
