# 野人同伴取水与采果

四套野人的原骨架增加两段一次性动作。取水时先向实际溪面下蹲，伸手后收回，再起身。采果进入林果点后伸手、收回并恢复站姿。沿用角色原站姿以及走跑使用的双关节骨链计算。持矛和盾的同伴在伸手前把装备移到背后，回到常规动作时装备重新跟随原来两只手的握点。原 14 段动作、骨架、网格和材质与上一版逐项一致。[源码制作脚本](../../scripts/bake-wild-people-work.py) · [导出检查](model.json)

取水和采果继续由房间服务器扣除真实资源，每成功执行一次分别播放 1.50 秒和 1.25 秒。多个同伴共用剩余库存。库存用尽时不会触发完成姿态。动作完成后继续当前生活行为，休养指令和防御可以优先中断。动作开始时间和库存沿现有快照同步。[双客户端记录](loopback.json)

普通男性和高级女性均从实际地图走进两个资源点。Apple M1 上 Godot 4.7.2 Compatibility 复验两套外观的脚底与握点。四组站定动作的脚骨最大平移 1.43 mm，真实脚底距脚下地面不超过 3.94 mm。单独按游戏的溪床高度和水位检查，两个角色的手指距溪面最近为 10.4 mm 和 16.5 mm。高级女性展示了同时装备矛和盾的情况。[实际动作画面](work-poses.jpg) · [原生测量](poses.json)

四套 GLB 每套 16 段动作通过场景导入。67 项生命周期、六条实际林地路线和四套走跑、跛行、转身回归均通过。两个真实 WebSocket 客户端共享 27 组快照并看见工作完成后恢复移动。复拍将 [定向测试](../../scripts/test-coop-wild-people-work.gd) 放进隔离 `coop` 工程，创建 `frames/`，用原生 Godot 运行并传入 `-- --capture`。截图只加载用于核查动作的局部溪床与角色模型。[回归数据](regressions.json)
