# 老鹰坠落与落地

原老鹰 Blender 绑定新增 `Fall`、`Collapse` 和静止侧卧的 `Dead`。空中失衡后收翼，近地或枝头从折翼动作倒下。两段末尾的骨骼和形键接到同一个侧卧姿态。36 根骨、抓枝挂点、28,164 个三角面和原十段活禽动画保持原始导出数据。三张贴图和折翼形键逐字节一致。[模型与散列](model.json) · [可重跑的 Blender 脚本](../../scripts/bake-camp-eagle-collapse.py)

Godot 4.7.2 Compatibility 在 Apple M1 上核验 51 个姿态样本。坠落和侧倒的末帧与静止片一致。侧卧时胸颈的最低蒙皮点距地约 4 mm，头约 26 mm，尸体横向中心距交互原点约 13 mm。[同机位画面](eagle-poses.jpg) · [导入姿态](godot-poses.json) · [源件测量](blender-poses.json)

实际命中记录路线时钟与老鹰模型原点，用坠落高度计算到达地表或湖面的时间。湖面上的尸体从水中漂向旧规则选定的可拾取岸点。藏在水里的物资仍从岸上搜取。客户端按同一房间时刻采样，死亡过渡结束前隐藏准星目标并由房间服务器拒绝搜取。旧尸体存档直接使用静态侧卧，掉落和归属照旧读取。[四处实际命中和存档回归](gameplay.json) · [定向游戏测试](../../scripts/test-coop-eagle-death.gd)

用真实路线验证枝头约 0.84 秒、陆地上空约 1.01 秒、地面约 0.60 秒。湖上飞行样本先坠 1.92 秒，再漂 2.20 秒。隔离房间的两个 WebSocket 客户端收到了 40 组同一时刻的快照，两次提前搜取都被拒绝。到岸后并发搜取同一只爪，恰有一人拿到。重启保留肉和羽毛，尸体直接显示侧卧。正式仓储回归 59 项通过。[双客户端记录](loopback.json)
