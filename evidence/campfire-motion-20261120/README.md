# 营火、火星与烟

实际游戏按房间的燃料截止时刻驱动火光。营火底部是可摆放的木柴与石圈。火舌、烟和火星由随镜头旋转的竖向画片绘制，火舌和烟按所在位置的阵风偏移。燃料剩余四秒时火光逐步减弱，燃尽后只剩石圈和木柴。绿色放置预览使用实际构件轮廓。底部周围半径 0.68 米的草和蕨叶在营火落地时清出，移除营火后恢复。 [火圈周围](ground-clearance.jpg)

Apple M1 上的 Godot 4.7.2 Compatibility 使用实际营地分块。两组同机位分别固定在暴雨的第 97.4 秒和夜间第 190 秒。夜间保持环境光，火的房间时间推进 0.16 秒，火舌及周围取景区有 16,497 个像素变化超过 12 个 RGB 通道级。通过 14 项摄像与状态检查，包括烧尽关灯、地面植被和摆放形状。 [暴雨及夜晚对照](rain-and-night.jpg) · [燃料耗尽](fuel-end.jpg) · [原生测量](native-report.json)
